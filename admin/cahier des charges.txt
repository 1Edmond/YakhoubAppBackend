CAHIER DES CHARGES

APPLICATION MOBILE E-COMMERCE MULTI-BOUTIQUES


1. PRÉSENTATION GÉNÉRALE
 1.1 Nom du projet
MultiShop Tchad (nom provisoire)

1.2 Objectif
Créer une application mobile unique hébergeant plusieurs boutiques gérées par des propriétaires indépendants, validés par un administrateur. Les clients peuvent commander des produits dans différentes boutiques via une seule application.

1.3 Plateformes
- Android (prioritaire)
- iOS (secondaire)

1.4 Technologies proposées
 Élément | Technologie

Frontend Mobile Flutter (recommandé) ou React Native
 Backend API  Node.js + Express ou Laravel
 Base de données  PostgreSQL ou MySQL
 Authentification  Firebase Auth (Google/Gmail)
 Paiement mobile  API Airtel Money / Moov Money
 Stockage images  Firebase Storage ou Cloudinary
 Notifications Firebase Cloud Messaging (FCM)
 Géolocalisation  Google Maps API


2. ACTEURS DU SYSTÈME

2.1 Administrateur (ADMIN)
- Gère l'ensemble de l'application
- Valide ou rejette les inscriptions des propriétaires de magasins
- Supervise toutes les transactions
- Gère les litiges et réclamations

2.2 Propriétaire de magasin (Vendeur)
- S'inscrit et attend la validation par l'ADMIN
- Crée et gère son magasin (nom, logo, description)
- Ajoute/modifie/supprime ses produits
- Gère les commandes reçues
- Consulte ses statistiques de vente

2.3 Client (Acheteur)
- S'inscrit avec Gmail, mot de passe et NNI ou passport
- Parcourt les produits de tous les magasins
- Ajoute des produits au panier
- Passe commande avec informations de livraison
- Suit ses commandes
- Peut annuler une commande (avec frais)

3.4.7 Système de Réduction de Prix

 Règles de fonctionnement
1. La réduction s'applique sur le prix total de la commande (pas par produit)
2. Le client sélectionne un palier parmi ceux autorisés
3. La demande est envoyée au vendeur pour approbation
4. Le vendeur peut :
   - ✅ **Accepter** la réduction demandée
   - ❌ **Refuser** la réduction
   - 🔄 **Proposer un autre montant** parmi les paliers disponibles
5. Si le vendeur accepte, le nouveau prix est appliqué
6. Si le vendeur refuse, le prix initial reste inchangé
7. La négociation est limitée à 2 allers-retours maximum
Règle
Le client peut demander une réduction sur le prix d'un produit selon des paliers prédéfinis.

5. Remboursement du montant de la commande (hors frais)
6. Statut de la commande : Annulée

### 3.4.6 Annulation de Commande (Modifié)

#### Frais d'annulation

| Élément | Valeur |
|---------|--------|
| **Frais de transport** | **1 000 FCFA (fixe et obligatoire)** |

#### Règles modifiées

1. L'annulation est possible **uniquement avant l'expédition** de la commande
2. Les frais d'annulation sont **fixes et obligatoires** : **1 000 FCFA**
3. Les frais sont payés par le client via **Airtel Money** ou **Moov Money**
4. Après paiement des frais, le montant de la commande est remboursé intégralement
5. Les frais de 1 000 FCFA **ne sont pas remboursables**

#### Processus d'annulation (mis à jour)

```
┌──────────┐     ┌──────────────┐     ┌──────────────┐     ┌──────────┐
│  Client  │     │   Système    │     │   Paiement   │     │ Commande │
│ demande  │────▶│ calcule      │────▶│ 1000 FCFA    │────▶│ annulée  │
│ annulation│    │ frais: 1000F │     │ Airtel/Moov  │     │          │
└──────────┘     └──────────────┘     └──────────────┘     └──────────┘
```

#### Écran d'annulation

| Élément | Valeur |
|---------|--------|
| Message | "L'annulation de commande entraîne des frais de transport de 1 000 FCFA non remboursables." |
| Montant des frais | **1 000 FCFA** (fixe, non modifiable) |
| Mode de paiement | Airtel Money ou Moov Money |
| Confirmation | "Je confirme vouloir annuler ma commande et payer 1 000 FCFA de frais" |
| Bouton | "Payer 1 000 FCFA et annuler" |

#### Remboursement

| Élément | Description |
|---------|-------------|
| Montant remboursé | Prix total de la commande (sans les 1 000 FCFA) |
| Délai de remboursement | 24 à 72 heures |
| Méthode de remboursement | Même méthode que le paiement initial |
